# sr-data-factory

Synthetic data generation for the experiments.

## Synthetic Data

Activate the `hybrid_modeling` environment (created from `environment.yml` in the hybrid-modeling folder) and run:

```bash
bash run_generate_data.sh
```

This creates .csv files in the `data` folder, which are used by the hybrid-modeling scripts.

## Respiration Data

The measured respiration .csv file is provided in the `data` folder.
